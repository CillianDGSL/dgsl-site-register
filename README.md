# DGSL Site Register — v3 prototype

Built from the supplied Handover / Take Back Sheet and the DGSL Site Register example.

## Included
- DGSL-style dashboard and work permit register
- Search and status filters
- 5 blocks / 30 apartments pre-loaded
- Handover form
- Handover checklist based on the supplied example
- Take Back section in the form
- Snag register
- Responsive desktop/tablet/mobile layout

## Next production phase
Connect the UI to Supabase (auth + database + storage), add photo uploads, real signatures, PDF generation, user roles, audit history and persistent records. Then deploy the front end through GitHub/Vercel or GitHub Pages.
